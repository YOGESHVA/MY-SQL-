Set Operators
-------------
Union : Combines results from two queries and remove duplicate rows.
columns must have the same number and type

Union All: combines result from two queries. including duplicate columns must 
have the same number and type

Intersect: returns rows that are common to both queries. columns must have 
the same number and type

Minus : returns from the first query that are not present in the second query columns 
must have the same number and type
Note: My sql doesn't support Minus directly

from student
union
select student_id
from placed_students

from student
union all
select student_id
from placed_students
